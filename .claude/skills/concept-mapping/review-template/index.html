?What this is

Before we can rank OMOP concepts by meaning, every concept in the OHDSI vocabulary is turned into a vector (an “embedding”) by the BioLORD model.

This is a one-off, shared by every project on this machine — you only rebuild it when the vocabulary is updated.

It's the prerequisite for the semantic suggestions in stage 2.

?What this is

For each source concept we propose candidate OMOP targets, from several complementary angles.

A reviewer accepts or rejects them later in the Linkr UI — nothing here is final.

  • Syntactic — string similarity on names (fast, catches typos & variants).
  • Semantic — meaning similarity via BioLORD embeddings (catches synonyms & paraphrases).
  • Statistical — compares the value distributions of numeric concepts. Not implemented yet.
  • Agentic (AI) — Claude reads each concept's metadata and reasons about the best target, with an equivalence judgement.
